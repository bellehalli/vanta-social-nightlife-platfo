## Portfolio safety
This is a fictional concept. All pages include `noindex,nofollow`.
Forms and demo checkout controls do not transmit or store information.

## Deployment
Static site: deploy repository root on Vercel with Framework Preset `Other`.
No build command or output directory is required.
